# dsh-plugin-model-matrix (模型矩阵)

> DeepSeek Harness 官方生态增强插件：**对话框双级联动模型选择器** + **提供商连通性实时状态灯** + **多渠道订阅统一管理套件**。

[English Documentation](README.md)

---

## 📖 解决的痛点与背景

在使用 DeepSeek Harness 进行多渠道模型交互（如本地接入 Nous Portal、Opencode Zen、Command Code、理想模型等）时，常常面临以下核心痛点：

1. **模型数量爆炸，挑花眼**：所有提供商的上百个模型全部堆在一个单列滚动列表中，每次切换模型都要在漫长的列表和吸顶标题间反复寻找。
2. **选择过程中自动刷新打断操作**：官方默认实现会在每次打开下拉菜单时无条件触发后台异步 `reload()`，当网络请求返回时列表重新渲染，不仅会导致滚动位置跳回首项，还会清空用户正在输入的搜索文字。
3. **连通性黑盒与全量轮询矛盾**：如果频繁对几十个模型全量测连，网络开销巨大且容易触发限流；如果不检测，又无法得知当前渠道究竟通不通。

`dsh-plugin-model-matrix` 针对上述问题进行了系统级重构与统一整合。

---

## ✨ 核心特性

### 1. 对话框双级联动选择栏（Two-Bar Selector）
将原先单一臃肿的模型下拉按钮拆分为 **两个水平并排的选择栏**：
- **左侧【提供商栏 (Provider)】**：
  - 直观展示当前所选渠道（如 `理想模型`、`Nous Portal`、`Opencode Zen`、`DeepSeek` 等）。
  - 点击弹出提供商列表，每项标明模型数量与连通性。
  - **智能联动**：切换提供商后，自动记忆上次使用的模型，并**顺畅自动展开右侧模型栏**。
- **右侧【模型细选栏 (Model)】**：
  - **只展示当前提供商下的模型**！告别上百个跨渠道模型的视觉干扰。
  - 渠道内部模型 > 4 个时自动提供搜索框，输入关键字实时模糊匹配过滤。
  - 推理强度（Reasoning Effort）调节：如果模型支持 `low` / `medium` / `high`，底部直接提供胶囊按钮即时切换，并在栏上展示（如 `· 中`）。

### 2. 机制调整：Provider 侧轻量实时状态灯
- **灯光位置**：状态灯呈现在 Provider 侧（包括提供商触发按钮与下拉列表项）。
- **按需单次测活**：**仅在您选择某个提供商时触发一次检测，且只检测该提供商旗下的第 1 个模型**。
- **杜绝全量开销**：绝不并发轰炸几十个模型，既保证了实时了解渠道通不通，又避免了频繁大量的刷新与限流风险。
- **状态颜色**：
  - 🟢 **绿灯**：渠道连通正常（测试模型成功响应）。
  - 🔴 **红灯**：渠道异常（未配置 Key、认证失败或服务离线，鼠标悬停看详细错误）。
  - 🔵 **蓝灯**：正在检测中（呼吸微动）。
  - ⚪ **灰灯**：尚未检测。

### 3. 彻底根治“自动刷新重置”
- 打开菜单时若目录已在内存中就绪，直接读取缓存秒开，**绝不再发起强制异步 reload**。
- 菜单展开期间，后台心跳轮询绝不重置用户正在输入的搜索词、绝不强制改变滚动位置。
- 提供商菜单与模型菜单顶部配有显式的手动「刷新」按钮，仅在需要时按需点测。

### 4. 完整的订阅渠道集成与管理设置页
内置三大主流订阅源管理套件（支持在“设置”页中开启独立控制面板）：
- **Nous Research Portal**：支持免费模型识别（`:free`）、认证引导与异步通道过滤。
- **Opencode Zen**：即插即用 9 大免费模型，移植会话门禁与专用请求头适配。
- **Command Code**：基于实际调用成本自动划分【免费 / 套餐 / 收费】档位，与 models.dev 实时报价联动。
- **统一设置页面板**：支持三档切换查看、搜索过滤、单项模型手动显隐开关（显式显示不受档位过滤影响）、单项/批量真实打点测连。

## 🧩 依赖与独立性说明（Dependency & Standalone Design）

很多人关心：“**这个插件是否依赖其他插件？还是独立可工作？**”

答案是：**核心功能 100% 独立运行，对外部订阅渠道采用“弱耦合、渐进增强”设计。**

### 1. 宿主基础依赖（零外部运行库）
* 本插件仅依赖 DeepSeek Harness 本身自带的核心框架：`@deepseek-ai/cordis` 内核、`slots` 插槽系统、`locale` 国际化与 `llm` 运行时。
* **无需额外安装任何第三方 npm 基础包**，无论在桌面端（Electron）还是网页版（Web）均可开箱即用。

### 2. 双选择栏 + 状态灯的通用性（100% 独立可用）
* 无论系统接入了什么提供商（DeepSeek 官方、DeepSeek 账号、企业内网模型、自定义 OpenAI 兼容网关等），**双选择栏和单模型测活状态灯机制均能 100% 独立生效**。
* 即使在全新、没有安装任何第三方订阅的干净 DSH 环境中，它依然能完美管理现有的官方或自建模型，享受纯净的双栏联动与杜绝自动刷新的体验。

### 3. 具体订阅渠道的协同机制（按需自适应，无强捆绑）
本插件作为模型控制中心，针对三大外部订阅做了自动适配，但**不形成硬性依赖**：

| 渠道 / 提供商 | 实际底层调用依赖 | 本插件的作用 | 若未安装底层插件时的表现 |
| :--- | :--- | :--- | :--- |
| **企业/内网网关**（如理想模型） | DSH 内置 `dsh-llm-pi-ai` | 双栏聚合、展示与连通性检测 | **原生支持**，不需任何外部插件 |
| **官方 DeepSeek** | DSH 内置官方驱动 | 双栏聚合、展示与连通性检测 | **原生支持**，不需任何外部插件 |
| **Nous Portal** | `dsh-nous-portal` | 专用单模型嗅探、免费通道标签、设置页集成 | 自动略过该项，**不报错、不影响其他渠道** |
| **Opencode Zen** | `dsh-opencode-zen` | 专用免密嗅探、9 大免费模型管理 | 自动略过该项，**不报错、不影响其他渠道** |
| **Command Code** | `dsh-commandcode-provider` | 成本档位划分、实时报价联动 | 自动略过该项，**不报错、不影响其他渠道** |

> **设计哲学**：
> 核心 UI 与控制逻辑完全自给自足；检测到环境中有对应订阅时自动激活增强逻辑；缺少某项时优雅降级静默，**绝对不会因为少装某个插件而导致整个界面崩溃或选择栏消失**。

### 5. 🛡️ 客户端升级自愈与常驻守护（Auto-Healing Guardian）
官方客户端（特别是处于 `nightly` 通道时）每次升级会全量覆盖 `resources/app.asar`，导致注入的 UI 补丁与扩展失效。本套件内置了**全自动自愈与守护体系**：
- **版本变更与完整性感知**：自动监控官方核心文件时间戳及客户端版本演进。
- **无损热补丁验证（Safe In-Place Byte-Aligned Patch）**：基于 AST 标记与精准字节对齐，安全执行零风险原位修补，自动生成备份文件 `app.asar.bak`。
- **后台常驻守护（Guardian Daemon）**：开机自启并以极轻资源开销静默守候，一旦检测到客户端升级自动瞬间恢复，无需用户任何手动干预。

## 🚀 安装与使用

### 一键安装到 DeepSeek Harness

在项目根目录运行安装脚本：

```bash
node scripts/install.js
```

安装脚本将自动把本插件链接至 `~/.dsh/profiles/desktop`，并写入 `cordis.patch.yml`。

### 启动/刷新应用

由于桌面客户端对快捷键做了保护，修改后请按以下方式重载生效：
- **快捷刷新**：在桌面端按 **`F12`** 打开控制台，在 Console 输入 `location.reload()` 并回车。
- **完整重启**：右键系统托盘（右下角）的 DeepSeek Harness 图标选择“退出”，重新打开客户端。
